>清远是小海的再生之地，南星对他也有别样的意义，我们参与其中不仅仅只是因为项目利益，更多是对他曾经经历的一种探视，为此项目小海和龚总付出了极大的努力，大家在推进中都坦诚相待，项目经过几轮讨论，最终成果在汇报过程中也得到过业主和厂长的认可，后来却不知什么原因，甲方也就不再联系了，仿佛也不好意思联系了。

南星的老办公楼为计划改造部分，此前是宿舍楼，后来改为办公，因企业客户到访时对此楼形象多次提出意见，故甲方有升级改造的意愿，老办公楼一楼主要功能包含一间员工餐厅和一间会议室，其中餐厅内包含了员工的活动室功能，有乒乓球台等设施，会议室也兼做了产品的展示。

## 项目信息
- 项目类型：厂房 / Project Type: Factory Building
- 完成年份：2025 / Completion Year: 2025
- 建筑面积：139455 m² / Project Area: 139455 m²
- 主要材料：耐候钢、彩釉玻璃、铝板、碲化镉光伏组件 / Materials: Weathering Steel, CdTe PV Module
- 建筑功能：厂房、立体车库 / Functions: Stereo Parking Garage
- 业主：焱唐能源科技(杭州)有限责任公司 / Client: Yantang Energy
